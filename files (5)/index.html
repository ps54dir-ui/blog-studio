⚙️ Google API 초기 설정 가이드

Blog Studio를 팀에서 사용하려면 Google Cloud Console에서
앱을 한 번만 등록하면 됩니다. (5~10분 소요)

1

Google Cloud Console 접속

아래 주소로 접속해 새 프로젝트를 만드세요.

https://console.cloud.google.com
2

API 활성화

좌측 메뉴 → API 및 서비스 → 라이브러리에서 아래 두 가지를 검색해 활성화하세요.

Google Drive API
Google Identity Services
3

OAuth 동의 화면 설정

API 및 서비스 → OAuth 동의 화면 → 외부 선택 → 앱 이름: "Blog Studio" → 저장

4

OAuth 클라이언트 ID 발급

사용자 인증 정보 → + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID
애플리케이션 유형: 웹 애플리케이션

승인된 JavaScript 원본에 추가:
https://kaleidoscopic-gnome-c77113.netlify.app
http://localhost:8080 (로컬 8080 포트)
http://localhost:3000 (로컬 3000 포트)
http://localhost (포트 없이 사용 시)

승인된 리디렉션 URI에 추가:
https://kaleidoscopic-gnome-c77113.netlify.app https://kaleidoscopic-gnome-c77113.netlify.app/ https://kaleidoscopic-gnome-c77113.netlify.app/index.html

5

클라이언트 ID를 아래에 입력

발급받은 클라이언트 ID를 붙여넣으세요. 입력 즉시 저장되어 다음에도 사용됩니다.

관리자 이메일 (쉼표로 여러 명 가능)
