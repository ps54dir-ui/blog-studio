## [L] 법적 체크 — 웹 검색 연계 (해당 분야만)

> ⚡ 이 카테고리는 체크리스트 내용이 아닌 웹 검색 결과를 최종 기준으로 삼는다.

L-01. [광고 표시] 사용자가 경제적 대가를 받는 원고인가?
      → YES: 제목 또는 첫 부분에 [광고]/[협찬]/[유료광고] 표시가 있는가
      → 위치: 2024년 12월 이후 끝부분 불인정 — 반드시 첫 부분
L-02. [AI 표시] AI 생성임을 명시하지 않고, 실제 사람의 경험·추천인 것처럼 작성된 구조인가?
      → YES: 표시광고법 기만광고 위험 — AI 생성 표시 문구 삽입 권장
L-03. [의료] 의료기관 홍보 + 환자 유인 구조인가?
      → YES: 의료법 제57조 사전심의 필요성 경고를 원고 하단에 삽입했는가
      → 웹 검색: "의료광고 사전심의 2025" 재확인
L-04. [의료] 치료경험담·전후비교·타병원 비방 구조인가?
      → YES: 의료법 제56조 위반 가능 — 구조 수정 또는 경고 삽입
L-05. [의사·약사 페르소나] 의료기관 홍보 구조와 결합됐는가?
      → YES: 의료법 경고 안내를 원고 완성 후 사용자에게 제공했는가
L-06. [건강기능식품] 식약처 허가 범위를 초과하는 효능 표현이 있는가?
      → YES: 식품표시광고법 위반 가능 — 표현 수정 또는 경고 삽입
      → 웹 검색: 해당 성분의 식약처 허가 기능성 재확인
L-07. [화장품] 미백·주름개선·자외선차단 표현이 있는가?
      → YES: 화장품법 제13조 기능성화장품 심사(보고) 여부 확인 안내 삽입
L-08. [금융·투자] 특정 종목 추천 + 유료 채널·CPA 구조인가?
      → YES: 자본시장법 개정(2024.8) 투자자문업 등록 여부 확인 경고 삽입
L-09. 면책 고지가 블로그·카페 하단에 삽입됐는가?
      의료·건강 / 법률 / 금융·투자 / 반려동물 / 음식·영양 분야 해당 시 필수
